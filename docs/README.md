# ARIA Documentation Index

This folder contains the documentation for **ARIA — AI Regulatory Inspection Accelerator**, a reusable, Azure-native Solution Accelerator currently in **Hackathon / IP Incubation** for Microsoft Global Hackathon 2026. PAFN (the Kuwait food safety inspection system) is the first production reference implementation of ARIA — see the root [README.md](../README.md) for the full product overview.
