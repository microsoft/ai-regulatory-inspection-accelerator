ARIA Agentic Workflow — Durable Functions
Durable OrchestratorOrders activities · checkpoints state · applies retry policy · routes failures

Agent 1 — Pre-Validation Agent

Validated bundle
  • Validates request metadata and document references
  • Checks document inventory, checksums, and supported formats
  • Stops technical failures before AI processing

Agent 2 — Document Extraction Agent

Canonical facts
  • Assesses document readability and extraction readiness
  • Extracts structured fields and confidence values
  • Normalizes dates, numbers, units, aliases, and languages

Agent 3 — Reasoning Agent

Evidence assessment
  • Performs semantic reasoning over normalized case evidence
  • Interprets relationships, dependencies, and contextual meaning
  • Produces conflicts, coherence signals, and a reviewer-readable assessment

Agent 4 — Rules and Policy Agent

Findings + risk
  • Loads current rules and reference data at runtime
  • Applies deterministic policy and consistency checks
  • Calculates findings, severity, confidence, and review need

Agent 5 — Recommendation and Delivery Agent

Explainable outcome
  • Builds PASS, HOLD, or FAIL recommendation
  • Links reasons to source documents, fields, and rules
  • Stores the outcome and notifies the adopting system
