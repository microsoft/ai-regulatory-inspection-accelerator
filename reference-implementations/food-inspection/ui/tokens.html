Multimodal Architecture Decision

Why AI Vision vs Deterministic Python Libraries (PyPDF2, pdfplumber, Tesseract)?

Hybrid Fallback Strategy

🐍 Deterministic Python Libraries (PyPDF / pdfplumber)

Best for: $0 token cost, ultra-fast text extraction from native digital PDFs.

Critical Blind Spots: Fail completely on scanned/photocopied documents, physical seals/stamps (Halal, Health Authority stamps), handwritten signatures/dates, or complex multi-column table layouts where raw text streams scramble columns.

👁️ AI Vision (Multimodal GPT-4o / Azure DI)

Best for: Understanding visual seals, handwritten text, complex layout geometry, Arabic/RTL visual alignment, and stamped certifications.

Cost Protection in ARIA: ARIA uses a hybrid fallback architecture. Digital text is processed via aria-text-mini ($0.15/1M tokens). Vision models (aria-vision) are invoked only when OCR confidence is <80% or visual stamp verification is explicitly required.

Cost reduction guide

Token optimization & saving strategies

Up to 94% cost reduction
⚡

Mini model tier routing

Route 95% of standard document text extractions to aria-text-mini ($0.15/1M tokens) instead of full gpt-4.1 ($2.50/1M). Fall back to vision models only when visual OCR confidence is <80%.

94% savings on text extraction
🔄

Prefix prompt caching

Structure static system instructions, field schemas, and inspection policy rules at the very front of the prompt. Providers auto-cache prefixes >1024 tokens for a 50% input discount.

50% discount on input prefix
🎯

Strict JSON schema responses

Use JSON response format mode to eliminate conversational preamble, reasoning text, and verbose markdown, cutting completion token overhead drastically.

65% reduction in output tokens
📦

Document hash deduplication

Compute SHA-256 hashes of incoming document pages before submission. Identical pages across multi-page evidence bundles are skipped, preventing duplicate extraction calls.

100% bypass on duplicate pages
